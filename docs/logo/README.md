# Logo options

Three candidates for the project logo, left to right in `options.png`:

1. **Bolt S** (`option-1.svg`): an S cut like a lightning bolt, white on orange.
2. **Spine** (`option-2.svg`): the curves of an S with a lightning bolt for its
   spine, drawn as one stroke.
3. **Strike** (`option-3.svg`): a soft orange S with a dark bolt through it.

Each is drawn on a 1024px canvas with an 824px rounded tile, so the PNG next to
it can be used as an app icon (`static/icon.png`) as it is.

## About the Svelte logo

These are original drawings. They use an S and Svelte's orange to say "this is
for Svelte"; they do not contain or modify the Svelte logo itself.

The Svelte branding repository (github.com/sveltejs/branding) has no licence
file, only conditions of usage. They ask that use of the logo and its colour
scheme does not suggest the Svelte project sponsors or endorses another
project, and that use to indicate compatibility is accurate and in good faith.
A project logo built out of the Svelte mark would be hard to square with the
first of those, so ask the Svelte maintainers before going that way.

`previous-icon.svg` is the placeholder icon the examples have used so far.
