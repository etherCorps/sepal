# Logo

`logo.svg` is the project's logo: a rounded tile struck in two by a lightning
bolt. The bolt is the gap between the halves, and the halves read as the two
lobes of an S. `logo.png` is the same at 512px.

`icon.svg` and `icon.png` (1024px) are the logo as an app icon: with the
margin macOS expects, and the bolt filled white so it looks the same on any
background. The starter template and the examples use it as `static/icon.png`.

Colours: `#ff7a3d` to `#f03400`, top left to bottom right.

It is an original drawing and does not contain the Svelte logo. Its orange is
close to Svelte's on purpose, to say what the project is for; the Svelte
branding guidelines (github.com/sveltejs/branding) ask that such use is
accurate and does not suggest the Svelte project endorses this one.
