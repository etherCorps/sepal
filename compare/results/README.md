# Comparison results

The reports here (`compare.md`, `mem.md`, `quick-1.md`, `damage-*.md`, `dialog-memory.md`, ...)
and the scripts that generate them (`make_*_report.py`) cite and read `compare/results/raw/`:
every run's record, log and screen-recording frames. That raw data is on the
`tracker-compare` branch only; main does not carry it. Check that branch out to re-run a
report or follow a reference into `raw/`.
