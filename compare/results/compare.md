# svelte-blitz before and now, gpuix-svelte and Tauri 2 (1,000 issues)

Apple M4 Pro, macOS 27.0.1, the Tracker bench build, window 1200x800 at 2x. Cells: median (min–max). svelte-blitz now and Tauri were measured in one session, interleaved run by run (`j3-tauri`, 1 warm-up + 3 runs each); svelte-blitz old and gpuix come from `mem-1000` (23 Nov, 1 warm-up + 3 runs). Sessions on different days drift by up to ~15%. Generated by `make_compare_report.py`; raw data in `compare/results/raw/` on this branch.

**gpuix-svelte is a port** (its own widgets, a CSS subset); Tauri runs the same components and CSS as svelte-blitz. Tauri's numbers include its WebKit WebContent, GPU and Networking processes.

**Why Tauri was missing before:** the `mem-1000` session was stopped on request on 23 Nov at 21:08 IST, right after Tauri's three idle runs; its other scenarios had not started (no log or record exists for them). It was not a failure of Tauri's runs. Every scenario ran here.
